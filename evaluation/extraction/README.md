# 연구 근거 자동 추출 실행 검증

현재 기본 추출기는 **v3**다. 페이지별 보완·별도 원문 검토·최종 요소별 수집 대장을 추가했고, 미해결 원문 항목이 있으면 본문 생성을 보류한다. 최종 v3 예측과 원문 판정이 고정되기 전에는 비교 점수를 확정하지 않는다. 진행 상태는 루트 `HANDOFF.md`에 기록한다.

이전에 완료한 **v2**는 [비교 보고서](v2/report.md) · [추출 JSON](v2/evidence.json) · [실행 재생 검증](v2/validation.json)에 보존했다. 같은42개 개발 참조 사실의 완전 보존은15/42→33/42, 작성 입력까지 완전 보존은3/42→24/42다. 코드·예측·판정·원본 해시를 별도로 고정했고 이전 v1 예측·참조는 변경하지 않았다. Codex 단독 개발 감사이며 전체 정확도나 다른 연구 자료의 일반화 성능은 아니다. v2에서도 표 수치 누락·AI 조언 출처 오분류·과도한 보류·유사 후보 과다 수집이 남는다.

```powershell
python -X utf8 -B evaluation/extraction/v2/validate.py
python -X utf8 -B evaluation/extraction/v2/evaluate.py
```

아래는 **보존한 v1 실행 기록**이다. `validate.py`는 `benchmark/baseline-code`의 v1 추출기로 캐시를 재생해 기존 예측과 일치하는지만 검사하며 현재 기본값으로 덮어쓰지 않는다.

내용 품질의 1차 원문 대조 평가는 [평가 보고서](benchmark/report.md)에 있다. 후보 34개·측정 항목 63개를 대조하고, 21쪽 표본의 필수 사실 42개로 누락을 확인했다. 후보 문서 충실도 32/34, 선택 출처 완전성 25/34, 표본 필수 사실 완전 보존 15/42다. 자동 검사 통과 후보의 횟수 오류와 정상 내용의 과도한 제외가 확인됐다. Codex 단독 개발 감사이며 전문가 독립 평가나 전체 문서 재현율이 아니다.

[CUDA 추출 결과](cuda-evidence.md) · [구조화 JSON](cuda-evidence.json) · [검증 기록](validation.json)

원본 PDF → Parse 원본 요소 → 구간별 사실 후보 → 원문 대조·유형·주장 강도·조건·측정값 → 작성용 근거의 경로를 실행했다.
골든 논문은 이 단계의 입력이 아니다. 수작업 근거 파일과 이전 추출 JSON을 읽지 않도록 차단한 실제 앱 API 재생도 통과했다.

## 이번 CUDA 실행

| 항목 | 결과 |
|---|---:|
| 추출 후보 | 34개 |
| 후보에 연결된 원문 인용·페이지 | 83곳 |
| 원문에 수치 표기가 있는 측정 항목 | 43개 |
| 수치 표기를 확인하지 못한 측정 항목 | 20개 |
| 기존 작성 요약의 선택 후보 | 17개 |
| 원문 대조 후 작성에 사용할 선택 후보 | 11개 |

20개 항목은 별도 `rejected_measurements`에 남겼다. 단위·버전 문자열·정성적 표현·범위·OCR 표기 불일치도 여기에 포함될 수 있어 모두 허위 수치라는 뜻은 아니다. 해당 후보를 작성 입력으로 승인하지 않는다.
가설·확인 필요·부분 뒷받침 후보도 원문과 함께 보존한다. 요약으로 선택되지 않은 후보도 보고서에서 확인할 수 있다.
기존 7장 초안은 갱신하지 않았다. 이 추출 버전으로 다음 작성 시 사용할 근거는 이전 17개와 구분해야 한다.

## 검증의 범위

- 원문 해시와 인용문·페이지·요소 ID, 측정 수치 표기의 존재를 코드로 검사했다.
- 수치가 존재해도 지표·단위·비교 조건·인과 해석이 맞다는 의미는 아니다. 원문의 이미지 숫자가 Parse에서 손실되면 확인 필요로 남을 수 있다.
- 유형·주장 강도·원문 뒷받침 판정은 LLM 보조 결과다. 현재 후보는 방법·결과에 치우쳐 있어 유형별 누락률을 별도 정답과 대조해야 한다.
- 구간별 후보 수와 작성 요약 개수에 제한이 있어 연구노트의 모든 사실을 추출했다는 보장이 없다.
- 34·43·11 등의 수치는 처리 결과의 개수이며 정확도·재현율 점수가 아니다. 개발 실행 중 원문 수치 불일치 처리를 보완했으며 독립 보류 평가가 아니다.
- 회귀 테스트 124개, 앱 추출 버튼·필터·이전 초안 보존을 확인했다.

## 재생

```powershell
python -X utf8 -B evaluation/extraction/validate.py
```

ignored 원본 Parse·모델 응답 캐시가 있어야 네트워크 없이 재생할 수 있다. 새 원본의 실제 추출은 다음과 같이 실행한다.

```powershell
python -X utf8 -B planned_paper.py --research-pdf "연구자료.pdf" --extract-only
```

추출 정확도 평가는 사전에 고정한 원문별 필수 사실·측정 조건·측정값·한계를 기준으로 사실 단위 정밀도·재현율, 수치·단위·조건 일치율, 원문 출처 정확도, 가설의 확정 사실 오분류율을 측정해야 한다. 평가용 정답은 작성 입력에 전달하지 않는다.
