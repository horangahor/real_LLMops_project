# 이전 기록 보관

현재 자동 연구 근거 추출의 입력으로 사용하지 않는 수작업 기록과 초기 초안을 보존한다. 원래 내용의 SHA-256과 이동 경로는 `manifest.json`에 있다.

- `manual-evidence/research_evidence.json`: 과거 수작업 근거. 현재 작성 경로는 원본 PDF에서 자동 추출하며 이 파일을 읽지 않는다.
- `legacy-drafts/paper_draft_section4_5.md`: 전체 논문 작성기 이전의 4·5장 초안. 새 생성에서 갱신하지 않는다. 앱의 이전 초안 대체 표시 경로만 이 위치를 가리킨다.

루트의 현재 초안·비교 모드 입력·참고 가이드, 평가의 고정 예측·정답·코드 스냅샷, 실행 재생에 필요한 `draft_history`는 유지한다. 현재 `research_extract_v3.py`는 v2의 1차 추출과 공통 스키마·v1의 보고서 렌더러를 사용하므로 버전 번호만 보고 해당 소스 파일을 삭제하지 않는다.
