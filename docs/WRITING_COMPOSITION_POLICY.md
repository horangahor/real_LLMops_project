# 논문 초안의 분량·핵심 내용·표·표기 공통 규칙

이 규칙은 연구 분야, 장 번호, 소절 이름, 특정 근거 ID에 의존하지 않는다. 추출한 논문 구조와 사용자가 정한 전체 분량을 입력으로 사용한다. 연구 근거 수집·승인 결과는 보존하고, 작성 계획·본문 작성·기존 편집·최종 출력에 적용하는 **구현 제안**이다. 이 문서 작성만으로 아래 동작이 코드에 적용되는 것은 아니다.

## 확인한 현재 결과와 원인

현재 완료 실행 `da05006e21ca964f77e6`의 분량 기록 기준이다. 글자 수는 공백 포함, 제목·인용 표시·표 제외다. 아래 절 번호는 진단 사례이며 규칙 조건으로 사용하지 않는다.

| 대상 | 목표 | 최종 본문 | 관찰 |
|---|---:|---:|---|
| 전체 | 30,000자 | 69,595자 | 목표의 약 2.32배 |
| 실행 시간 비교 | 2,143자 | 10,424자 | 45개 문단 |
| 커널 축소와 최적화 효과 | 2,143자 | 5,838자 | 개별 변경과 관측이 장황하게 이어짐 |
| 측정 및 반복 조건 한계 | 1,429자 | 7,340자 | 개별 사례 설명이 길게 반복됨 |
| 비교 조건 통제의 한계 | 1,429자 | 15,871자 | 소절 하나가 과도하게 커짐 |

현재 분량 정책은 작성 목표를 전달하고 초과를 기록한다. 초과가 실제 축약 과제로 연결되지는 않는다. 편집 지침에는 목표 초과만으로 수정 범위를 넓히지 말라는 제약도 있다.

평가 장에 선택된 표 25개는 `render_paper`가 장 본문 뒤에 모두 출력한다. 마지막 소절 뒤에 삽입되므로 그 소절의 표처럼 보이며, 소절 목적에 따른 선별·배치가 없다. 표를 덜 쓰라는 본문 프롬프트만으로 해결되지 않는다.

완성 Markdown에서 `~~`와 `<del>` 태그는 발견되지 않았다. `~`가 있는 줄은 25개이며 수치 범위와 근삿값 표기가 섞여 있다. 관찰된 취소선은 범위 기호의 Markdown 해석으로 생겼을 가능성이 있다. 화면 자체를 대조해 확정한 진단은 아니다.

## 1. 소절은 핵심 질문에 답하는 단위다

- 작성 계획의 각 소절에 설명할 질문 또는 목적과, 그 답에 필요한 핵심 주장·관찰을 명확히 한다. 기존 필수 작성 항목을 이 목적에 맞게 구체화하며, 추출한 근거 목록 자체를 소절의 목차로 사용하지 않는다.
- 작성자는 핵심 주장 → 대표 근거·비교 → 해석 범위의 흐름으로 쓴다. 근거 하나마다 문단 하나, 버전 하나마다 실행 기록 하나를 작성하지 않는다.
- 같은 결론을 지지하는 반복 관측은 조건이 실제로 같은 경우 대표 관측으로 설명한다. 반대 결과·실패·조건 차이·사용자 승인 범위를 없애 유리한 결론으로 만들지 않는다.
- 세부 로그·구현 변경 이력·전체 수치 목록은 그 소절의 질문에 답하는 데 꼭 필요할 때만 본문에 포함한다. 선택하지 않은 자료는 근거 저장소에 남긴다.
- 소절을 비우거나 삭제해서 간결함을 달성하지 않는다. 제목을 유지한 채 한 문장만 남기는 형식적 통과도 목표로 삼지 않는다.

## 2. 분량 목표는 실제 축약 행동과 연결한다

- 전체 목표를 작성할 장의 역할과 추출된 소절 수에 따라 나눈다. 장·소절이 바뀌면 같은 배분 정책을 다시 계산한다. 특정 절 번호별 상수는 두지 않는다.
- 소절의 입력 근거 수, 원문 페이지 수, 분할 API 요청 수가 늘어도 그 소절의 총분량 목표가 늘어나지 않는다.
- 분할 조각의 목표 합계뿐 아니라 합쳐진 소절의 실제 분량을 확인한다. 문단 수와 단일 문단 길이도 함께 기록해, 여러 쪽의 내용을 문단 하나로 붙여 통과하지 못하게 한다.
- 소절이 목표를 크게 초과하면 기존 작성·편집의 보완 과제에 **핵심 내용을 남긴 축약**을 명시한다. 전체 논문 편집까지 기다리지 않고 소절 작성과 장별 편집 경계에서 다룬다. 허용 오차는 공통 설정으로 관리하며 사례별 예외를 만들지 않는다.
- 축약 순서는 반복 설명, 같은 결론의 반복 관측, 표와 중복되는 수치 열거, 다른 소절에서 이미 설명한 배경, 작성 이력 순이다. 연구 주장의 해석을 바꾸는 조건·반례·한계는 보존한다.
- 글자 수에서 문자열을 잘라내거나 JSON 출력을 중간에 끊지 않는다. 문장을 제거하면 그 문장에만 연결된 인용도 함께 정리하고, 남은 주장에 필요한 근거 연결은 유지한다.
- 제한된 보완 후에도 초과하면 본문을 보존하되 **분량 목표 미충족** 상태를 최종 품질 보고서와 화면에 명시한다. 생성 완료와 편집 목표 달성을 같은 상태로 표시하지 않는다.

## 3. 표는 후보 자료이며 모두 본문에 싣지 않는다

- 연구 자료의 표 목록과 출판할 표 목록을 구분한다. 수집·승인됐다는 이유만으로 본문 표가 되지는 않는다.
- 본문 표는 특정 핵심 주장·연구 질문을 설명하는 역할을 가져야 한다. 단순 실행 화면, 반복 출력, 같은 추세를 반복하는 표는 그 자체로 본문 표가 될 근거가 부족하다.
- 선택 기준은 핵심 질문과의 관련성, 비교 조건의 해석 가능성, 다른 표에 없는 정보, 글보다 표로 보여줄 이점이다. 선택하지 않은 표의 제외·보관 이유도 기록한다.
- 같은 질문에 대한 표를 줄일 때는 대표 비교를 택하거나 조건이 호환되는 자료를 하나의 비교표로 구성한다. 조건·지표·단위가 다른 값을 같은 실험처럼 합치거나, 없는 평균·통계·성능 향상 수치를 만들지 않는다.
- 본문은 선택한 표의 핵심 관찰과 해석 한계를 설명하며 모든 셀과 행을 문장으로 되풀이하지 않는다. 중요한 반례나 상충하는 결과를 표 선별 과정에서 숨기지 않는다.
- 표는 관련 주장과 소절에 명시적으로 연결하고 해당 설명 가까이에 출력한다. 장에 배정된 표를 장 끝에 일괄 부착해 마지막 소절에 몰아넣지 않는다.
- 본문에서 제외한 원본 표와 전체 기록은 캐시에 유지한다. 별도 자료·부록을 만들지는 기존 구조와 사용자 선택에 따른다.

## 4. 각 절은 자기 역할의 수준에서 설명한다

- 배경·문제 제기는 왜 연구가 필요한지 설명하고, 모든 구현 이력과 실행 결과를 미리 나열하지 않는다.
- 방법은 무엇을 어떻게 수행했는지와 필요한 조건을 설명한다.
- 평가·결과는 핵심 질문별 대표 관찰·비교·해석을 설명한다. 시간 순서대로 실험 일지를 재현하지 않는다.
- 한계는 한계의 유형 → 해석에 미치는 영향 → 보완 방향으로 묶는다. 앞선 모든 측정값과 구현 내용을 다시 열거하지 않는다.
- 결론은 핵심 답과 적용 범위를 정리한다. 새로운 실험이나 앞 장의 전체 내용을 다시 쓰지 않는다.
- 이러한 역할은 장 번호가 아닌 계획의 목적·필수 내용에 따라 적용한다. 하나의 장에 여러 역할이 결합돼 있으면 실제 소절 목적을 기준으로 판단한다.

## 5. 논문 텍스트와 출력 문법을 분리한다

- 취소선, 수정 전후 표시, 작성 지시, 이모지 등 편집 흔적을 최종 논문 장식으로 사용하지 않는다. 필요한 과학적 기호·수식·코드 표기까지 금지하지 않는다.
- 범위 기호 `~`와 근삿값 `~`의 의미를 구분한다. 출력에서는 Markdown 이스케이프를 적용하거나 범위임이 확실한 경우에만 범위 기호를 정규화한다. 모든 `~`를 범위 기호로 바꿔 근삿값·경로·코드의 의미를 바꾸지 않는다.
- 코드·수식·리터럴을 고려해 출력 단계에서 처리한다. 원본 근거·저장된 수치·인용 ID는 표시 문제 때문에 변경하지 않는다.
- 실제 취소선 문법으로 삭제한 내용을 자동으로 되살려 사실 주장으로 사용하지 않는다. 불필요한 편집 표시인지 내용 삭제 의도인지 구분한다.

## 적용 책임과 확인 기준

| 위치 | 책임 | 확인 기준 |
|---|---|---|
| 작성 계획 | 소절 목적·핵심 주장·필요한 후보 근거·본문 표 선별·표의 소절 연결 | 입력 자료가 많아도 모든 기록·표를 자동 배정하지 않음 |
| 소절 작성자 | 핵심 질문에 맞춰 근거를 종합하고 총분량을 나눠 사용 | 분할 조각을 합친 분량과 주장 범위 확인 |
| 기존 1차 편집자 | 소절 내부·사이의 반복을 줄이고 초과 소절을 축약 | 소절과 핵심 설명·조건·한계·남은 인용 보존 |
| 기존 2차 편집자 | 장 사이 역할·중복·전체 분량의 균형 확인 | 한계·결론에서 앞선 본문 전체를 반복하지 않음 |
| 코드·최종 출력 | 분량 측정, 선택 표만 명시 위치에 출력, Markdown 안전 표기 | 원본 자료 보존, 숫자·코드·수식 의미 유지 |
| 품질 보고서 | 생성 완료와 편집 목표 달성 구분 | 소절별 목표·최종 글자 수·초과율·표 선택/보관·표기 진단을 함께 기록 |

새로운 상시 에이전트 계층을 추가하는 규칙이 아니다. 근거 수집을 다시 수행하지 않고 기존 작성·편집 역할과 결정적인 출력 처리를 개선한다. 다른 구조로 검증할 때도 숫자가 붙은 절 이름이나 특정 분야의 지표를 조건으로 사용하지 않는다.
